# ADR-0007: 생산 지시에 BOM 복사본 보관

> v1 결정 이력. v2에서는 [ADR-0009](0009-factory-production-flow.md)가 승인 개정 사용과 실제 소비 분리로 부분 대체한다. 지시의 생산 기준을 고정하는 원칙은 유지한다.

- 상태: v1 채택·구현 / v2 승인 개정·실제 소비 분리로 부분 대체; 검증 이력은 [PROGRESS](../PROGRESS.md) 참조
- 기록일: 2026-09-11
- 출처: 기존 v1 상세 설계, PRD-V1 BR-07의 구현 방식
- 관련 요구사항: [PRD-V1](../PRD-V1.md) FR-02, FR-04~06, BR-07

## 배경

부분 생산 도중 BOM이 수정되어도 기존 지시의 자재 기준은 바뀌면 안 된다.
당시 v1 MVP는 BOM 전체 개정 이력과 승인 절차를 요구하지 않았다. v2는 승인 개정을 요구하며 이 제외를 이어받지 않는다.

## 결정

생산 지시 생성 시 부품 ID와 단위 소요량을 지시 소속 데이터로 복사한다.
이후 자재 소비는 현재 BOM이 아닌 지시 복사본으로 계산한다.
BOM 전체 교체와 지시 생성은 같은 BOM 헤더를 잠그는 규칙을 사용해 구성 일부가 섞이지 않게 한다.
v1 지시 복사본은 수정하지 않는다. 품목 수정·삭제 제외 범위도 [PRD-V1](../PRD-V1.md)을 따른다.

## 대안

| 대안 | 선택하지 않은 이유 |
| --- | --- |
| 실적마다 최신 BOM 조회 | 지시 생성 당시 기준을 보존하라는 BR-07을 충족하지 못한다. |
| 불변 BOM 버전을 만들고 지시에서 참조 | 가능하지만 당시 v1 요구에는 없는 전체 개정 관리 구조가 추가된다. v2는 승인 개정 모델을 채택한다. |
| BOM 변경을 전면 금지 | BOM 교체 요구 FR-02를 충족하지 못한다. |

## 결과와 단점

기존 지시와 새 지시의 기준을 명확히 분리하고 지시별 필요 자재를 재현할 수 있다.
지시마다 BOM 행이 중복되며, 모든 BOM 변경 이력을 복원하는 기능은 제공하지 않는다.
향후 품목 이름·단위 변경까지 과거 표시를 보존해야 한다면 현재의 ID·수량 복사만으로 충분하지 않을 수 있다.

## 검증과 재검토 조건

BOM A로 만든 지시가 BOM B로 변경된 뒤에도 A를 사용하고, 신규 지시는 B를 사용하는지 확인한다.
지시 생성과 BOM 교체의 동시 요청에서 완전한 A 또는 B만 복사되는지 확인한다.
개정 승인, 적용일, 변경 감사나 다단계 BOM이 필요해지면 버전 참조 모델을 재검토한다.

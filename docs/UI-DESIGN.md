# 프론트엔드 디자인

사용자 지정 참고: [NASEEJ — ERP System (Behance)](https://www.behance.net/gallery/254067381/NASEEJ-ERP-System).
2026-09-11 공개 프로젝트의 표지, 디자인 시스템, 라이트/다크 업무 화면을 확인했다.

이 문서의 적용·화면·검증 이력은 **구현된 v1 UI** 기준이다. [PRD v2](PRD.md)의 전체 구현은 진행 중이지만 화면 완료·브라우저 검증은 최종 통합 증거 전까지 대기다. v1의 실적 즉시 양품 입고·자동 완료 UI를 v2 검사/입고 분리 구현으로 해석하지 않는다.

## 적용 방향

밝은 사이드바와 회색 작업 배경, 오렌지 강조색, 간결한 선형 아이콘, 요약 카드,
데이터 표와 상태 배지를 기존 조립 제조 ERP에 맞춰 구성한다. 화면 밀도보다 본문과 수량의 판독성을 우선한다.
참고 페이지의 오른쪽에서 왼쪽으로 읽는 레이아웃은 한국어 환경에 맞게 왼쪽 메뉴로 바꾸었다.
NASEEJ 로고, 원본 화면 이미지, 고객·매출 수치나 문구는 애플리케이션에 복사하지 않는다.

참고 팔레트의 오렌지 `#F97316`, 제목색 `#2A313A`, 배경 `#F8F9FB`를 출발점으로 한다.
흰색 버튼 글씨와 작은 설명문은 읽기 쉽도록 더 진한 오렌지·회색으로 조정했다.
다크 모드는 `#141414` 배경과 별도 표면·테두리·텍스트 색을 사용한다.
새로운 UI 패키지 의존성은 추가하지 않았다. 사용자 후속 요청에 따라 공식 LINE Seed KR 웹폰트를 아래와 같이 적용한다.

## 타이포그래피와 가독성

2026-09-11 사용자 피드백에 따라 기존 10~12px 위주의 표·보조 문구를 확대했다.
글꼴 이름만 바꾸는 것이 아니라 크기, 실제 굵기, 명암 대비, 줄 간격과 입력 영역을 함께 조정한다.

| 용도 | 기본 크기 | 실제 굵기 |
| --- | --- | --- |
| 페이지 제목 | 30px, 작은 화면 28px | Bold 700 |
| 구역 제목 | 18px | Bold 700 |
| 요약 숫자 | 32px | Bold 700 |
| 본문·품목명·표 수량·입력값 | 15px, 모바일 입력 16px | Regular 400, 중요한 수량만 700 |
| 메뉴 | 15px, 모바일 14px | 기본 400, 선택된 메뉴 700 |
| 표 머리글·입력 라벨·탭 | 14px | Bold 700 |
| 상태 배지·보조 설명·문서 식별자 보조 표기 | 13px 이상 | 설명 400, 상태 700 |

CSS 루트는 브라우저 기본 크기를 존중하는 `100%`, 각 글자는 `rem` 단위다.
본문 줄 높이는 1.6, 표는 1.65이며 본문 자간을 인위적으로 좁히지 않는다.
기본 입력 높이는 46px, 버튼은 44px로 늘렸다. 모바일에서도 작은 글자로 줄여 넣지 않고 줄바꿈·표 내부 스크롤을 사용한다.
Regular/Bold만 로드하며 Thin이나 존재하지 않는 500/600/650 등의 중간 굵기와 가짜 Bold를 사용하지 않는다.
품목 코드도 LINE Seed KR로 표시하고 수량에는 `tabular-nums`를 지정한다.

라이트 본문은 `#202833`, 보조 글자는 `#4B5563`, 표 머리글은 `#344054`다.
다크 본문은 `#F3F5F7`, 보조 글자는 `#C2C9D3`다. 오렌지는 강조에 한정하고 일반 데이터는 본문색으로 읽는다.
일반 텍스트·상태 배지·플레이스홀더의 4.5:1 이상 대비를 검사한다.
기준은 [WCAG 2.2의 텍스트 최소 대비](https://www.w3.org/TR/WCAG22/#contrast-minimum)이며,
선택한 화면의 자동 대비 검사 통과를 제품 전체의 접근성 인증으로 표현하지 않는다.

### 글꼴 출처와 배포

[LINE Seed 공식 한국어 페이지](https://seed.line.me/index_kr.html)의 공식 배포본
`LINE_SeedKR_2023.09.06`, 글꼴 내부 버전 1.000에서 Regular/Bold WOFF2를 그대로 사용한다.
글꼴은 `apps/web/static/fonts/line-seed-kr`에서 같은 출처로 제공하며 런타임 외부 CDN·시스템 설치에 의존하지 않는다.
`font-display: swap`과 두 굵기 사전 로딩을 사용하고, 파일 로딩 실패 시 시스템 글꼴로 표시한다.
저작권은 LY Corporation에 있으며 SIL Open Font License 1.1을 따른다.
같은 폴더의 `OFL.txt`에 공식 라이선스 전문, `source.json`에 출처·수집일·파일 SHA-256을 보관한다.
서체를 변환하거나 부분 집합으로 만들거나 운영체제에 설치하지 않는다.

## 화면과 동작

- 품목·생산 요약은 기존 API의 전체 `pagination.total`을 사용한다. 현재 페이지의 행 수를 전체 수로 표시하지 않는다.
- 재고 요약은 모든 페이지의 품목 수를 세며, 서로 다른 단위의 재고 수량은 합산하지 않는다. 재고 0은 미입고 품목도 포함하므로 자재 부족 판정으로 표현하지 않는다.
- 요약을 읽는 동안 로딩을 표시하고, 실패하면 `—`와 재조회 버튼을 보여준다. 임의의 0이나 성장률을 넣지 않는다.
- 상단 검색은 실제 품목 목록 검색으로 이동한다. 메뉴 접기, 테마 전환, 안내 펼치기는 실제 작동한다. 알림·내보내기 등 미구현 버튼은 추가하지 않는다.
- 디자인 선호로는 테마와 메뉴 접기를 브라우저에 저장한다. 테마 전환은 입력 폼을 다시 만들지 않아 작성 중 입력을 유지한다. 별도의 v1 불확실한 저장 요청 보존은 기존 멱등성 동작이며 이 문장의 ‘디자인 선호’와 구분한다.
- 모든 기존 화면에 공통 색상·간격·표·폼 스타일을 적용한다. 작은 화면에서는 메뉴를 가로 탐색으로 바꾸고 표 내부에서만 가로 스크롤한다.

## v1 구현 범위와 검증 이력

업무 API·DB 스키마·수량 정책·멱등성 코드는 당시 디자인 작업에서 변경하지 않았다. v1 디자인에는 애플리케이션 로그인·가상 매출 그래프·대시보드를 추가하지 않았다.
후속 공개 배포는 사용자 결정에 따라 proxy Basic Auth를 사용하지 않는다. v1 익명 조회·쓰기 위험은 남으며 TLS·Host 검사·loopback을 접근 권한으로 표현하지 않는다. 실제 배포 절차는 [DEPLOYMENT](DEPLOYMENT.md)를 따른다.
원본 참고 이미지와 변경 전 프론트엔드 백업은 추적 제외된 `.local/design-reference`에만 보관한다.

`summaries.test.ts`는 전체 집계·오류 처리를, `tests/browser/design.spec.ts`는 테마·메뉴·검색·요약·반응형 화면을 검증한다.
`tests/browser/typography.spec.ts`는 실제 Regular/Bold 렌더링, 화면별 글자 크기·대비, 모바일 글자 확대와 입력 유지를 검증한다.
기존 HTTP/업무 UI 테스트도 유지한다. 실제 실행 결과와 남은 항목은 [PROGRESS](PROGRESS.md)에 기록한다.

## v2 화면 인수 요구 — 구현 진행 중, 검증 대기

- v1 시연과 v2 경로·수량 의미를 구분한다. v2 지시에는 합격 입고 목표·허용 착수·신규 산출·검사대기·합격 미입고·순입고·부적합·재작업·폐기를 각각 표시한다.
- 창고와 지시 현장의 불출·소비·반납을 구분하고 검사나 입고를 자재 재차감으로 표시하지 않는다. 목표 달성만으로 자동 마감 배지를 붙이지 않는다.
- 로그인 사용자·현재 역할·배정 지시를 표시하되 UI 숨김은 서버 권한을 대신하지 않는다. 만료/역할 철회·계정 전환 후 다른 사용자의 불확실한 요청을 재제출하지 않는다.
- 보류·재개·초과 합격·목표 변경·역분개는 [FACTORY-PLAN 7절](FACTORY-PLAN.md#7-구현-인수-경계와-결정-게이트)의 권한·상태·사유·잔량 조건을 안내한다. 거절 시 입력을 보존하되 현재 권한을 우회하지 않는다.
- 테마·가독성·반응형은 기존 방향을 유지한다. v2 역할별 실제 화면과 PRD 대표 흐름을 관측한 뒤 [PROGRESS](PROGRESS.md)에 증거를 추가한다. 과거 v1 스크린샷/테스트 수를 재사용해 v2 통과로 표시하지 않는다.


## 2026-09-14 공장 화면 디자인 통합

v2도 v1의 공통 사이드바, 상단 탐색, 테마, 아이콘과 요약 카드를 재사용한다. 별도의 공장 헤더와 가로 메뉴는 제거했다.
작업 지시는 전체 너비 목록을 기본으로 하며 검색과 상태 필터를 제공한다. 생성·상세는 별도 보기로 열고 목록으로 돌아올 때 필터를 유지한다.
완제품 선택 전 BOM·검사 기준은 비활성화하며 제품 변경 시 선택을 초기화한다. 승인 기준이 없으면 기준정보 등록을 안내한다.
상세에는 생산 수량과 상태별 다음 작업 안내를 표시한다. 내부 기능 번호와 담당 사용자 UUID는 주요 화면에서 제거한다.
